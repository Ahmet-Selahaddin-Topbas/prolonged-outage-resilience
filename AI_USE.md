# AI use statement
*Last updated 7 Nov 2026. Updated whenever practice changes.*

- **Model and code:** the outage-scan model was built together with Claude (Anthropic) in an interactive session. The author sets the question, scope, assumptions and interpretation; Claude writes and tests code on request. All code is run and its self-tests are visible in `1_models/`.
- **Writing:** summaries, blueprints, registers and templates were drafted with Claude and edited by the author. The author is responsible for every statement.
- **Literature:** searches were run with AI assistance; the register states which works were read in relevant sections (6) and which only at abstract level (22). Citations were checked against the sources; two errors found on 30 Oct 2026 are recorded in the Process Journal.
- **Other assistants:** an AI assistant suggested alternative project titles; they were rejected as overclaiming.
- **Faculty guidance:** the author was advised to carry out the modelling with Claude, and does so openly.
- **Programme rules:** if a funding programme (for example TÜBİTAK 2209-A) requires a separate declaration, it is made in the programme's own format.
- **Rule for outputs:** nothing generated by AI is presented as a result unless it can be traced to data and code in this repository.
