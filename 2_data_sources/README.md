# 2_data_sources: what the model stands on

| Item | What it is |
|---|---|
| `data_register.csv` | One row per source (D01 to D51): what it is, link, how it is used, status |
| `Literature_and_Source_Register.pdf` | The 28 works read for this study, with notes on what each gives and does not give |
| `Literature_Search_Log_30Oct2026.md` | How the literature search was done |
| `site/` | Campus site register (category level), campus diagram, and the field form used on campus walks. The filled form stays private; only category-level results are published |
| `synthetic/` | Synthetic inputs, labelled as such |

Source codes (D01...) are used across the repository, so a claim can be traced to its source.
