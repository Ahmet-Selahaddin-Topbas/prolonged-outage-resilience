# pre_hypothesis: what we expected before seeing results

- `v1.0_2026-10-30_original.md` is frozen and never edited. It records the predictions made on 30 October 2026 from physical reasoning.
- A revision (for example one grounded in the literature) is added as a **new dated file** from `_template_revision.md`. The old file stays as it is, so the change in thinking can be seen.
- Predictions are compared with results only after the model runs on campus data.
