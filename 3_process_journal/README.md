# Process Journal
**What it is.** The dated record of *what we did*. One file per week (`W00.md`, `W01.md` ...), written on Fridays.
**Rules.** Entries are never deleted or rewritten. A mistake is corrected in a new entry (section 6 of a later week). Every entry has a date. People are named only with consent. Raw e-mails and screenshots are not published.

**Start a new week:** copy `_template.md` to `W01.md` (then `W02.md` ...) and fill it.

## Template for each week
1. **What happened** (facts, with dates)
2. **Decisions** (decision, alternatives, why)
3. **Sources used** (codes from `2_data_sources/data_register.csv`)
4. **What changed in the model and documents** (file and version)
5. **Open questions and next week**
6. **Corrections to earlier entries**
*AI assistance:* one line per week saying where AI tools were used.

W00 additionally holds: how the idea started and evolved, why this region and this question, the contact log (date, role, one-line outcome), the literature search record and the first predictions.
