# Next-version roadmap (outside the current scope)
Kept apart on purpose so that the current version stays small and checkable.
- **Decision-support packaging:** turn the model into a usable tool for decision makers (interface, scenario presets).
- **Economic layers:** techno-economic, cost-benefit and life-cycle assessment, multi-criteria decision analysis.
- **Dynamic load shedding and priority policies** between tiers.
- **Equipment failures, tank pressure and inverter limits.**
- **Second site (Kashiwa) with Japanese weather and outage data.**
Each item needs its own question, data and checks before it enters the model.
